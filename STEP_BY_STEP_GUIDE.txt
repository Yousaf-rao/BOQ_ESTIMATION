STEP 5: TEST ON REAL DRAWINGS (DAY 3-4)
═══════════════════════════════════════════════════════════════════════════

Use this code to predict on large CAD drawings:

```python
from ultralytics import YOLO
import cv2
import numpy as np

model = YOLO('best.pt')

# Load big CAD drawing (14,000 × 10,000 or any size)
img = cv2.imread('big_drawing.jpg')
h, w = img.shape[:2]

# Tile prediction
TILE = 640
STEP = 480  # 25% overlap
all_dets = []

for y in range(0, h - TILE + 1, STEP):
    for x in range(0, w - TILE + 1, STEP):
        tile = img[y:y+TILE, x:x+TILE]
        results = model.predict(tile, conf=0.30, imgsz=640, verbose=False)
        
        for box in results[0].boxes:
            cls = int(box.cls[0])
            conf = float(box.conf[0])
            x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
            
            # Convert to full image coordinates
            all_dets.append({
                'class': cls,
                'conf': conf,
                'x': int(x + x1),
                'y': int(y + y1),
                'w': int(x2 - x1),
                'h': int(y2 - y1)
            })

# Remove duplicates (NMS)
# (code for NMS...)

print(f"Found {len(all_dets)} symbols")
```
