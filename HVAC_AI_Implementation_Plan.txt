=========================================================
      HVAC AI SYMBOL DETECTION & BOQ ESTIMATION PLAN 
           (Synthetic Data + YOLOv11 + SAHI)
=========================================================

Is plan ko step-by-step follow karein. Har phase apne aap mein ek complete milestone hai.

---------------------------------------------------------
PHASE 1: DATA PREPARATION & ENVIRONMENT SETUP
---------------------------------------------------------
Sub-phase 1.1: Environment Setup
- Python 3.10+ install karein.
- Terminal mein libraries install karein: (pip install ultralytics sahi opencv-python pandas pillow)
- Project folder structure create karein (jaise data/icons, data/backgrounds, dataset/images, dataset/labels).

Sub-phase 1.2: Icon Cropping (The "Symbols")
- Apni drawing ke Legend se har symbol (Supply, Return, Diffusers) ko alag alag scan/crop karein.
- Photoshop ya kisi online background remover se unka background transparent karein (.png format).
- In sab transparent icons ko 'data/icons' folder mein save karein (e.g., supply_diffuser.png).

Sub-phase 1.3: Background Collection (The "Canvas")
- Kam az kam 5 se 10 clear "empty" floor plan drawings nikalen jin par koi symbols mojood na hon.
- In khali drawings ko 'data/backgrounds' folder mein save karein.

---------------------------------------------------------
PHASE 2: SYNTHETIC DATA GENERATION (Automation)
---------------------------------------------------------
Sub-phase 2.1: Script Execution
- Hamare likhe hue 'generate_synthetic_data.py' script ko run karein.
- Yeh script icons ko backgrounds par randomly paste karegi (scale aur rotate karke).
- Target: Kam az kam 2000 se 5000 images generate karna.

Sub-phase 2.2: Data Verification
- Generate hone wali images (dataset/images/train) ko open kar ke check karein.
- Unke sath moujood bounding box coordinates (dataset/labels/train) ki .txt files check karein.
- Ensure karein ke classes.txt theek se generate ho chuki hai.

---------------------------------------------------------
PHASE 3: YOLOv11 MODEL TRAINING
---------------------------------------------------------
Sub-phase 3.1: Dataset Prep (YAML)
- Ek 'data.yaml' file banayen jisme train, val images ka path aur classes ke naam likhe hon.

Sub-phase 3.2: Model Training
- Google Colab ya apne Local PC (GPU ke sath) par Ultralytics YOLOv11 (m) start karein.
- Command: `yolo train data=data.yaml model=yolov11m.pt epochs=100 imgsz=640`
- Results (metrics) check karein mAP50 aur mAP50-95 ke liye.

---------------------------------------------------------
PHASE 4: INFERENCE PIPELINE (SAHI & OCR)
---------------------------------------------------------
Sub-phase 4.1: Integrate SAHI (Slicing)
- Ek bari (actual) test drawing lein.
- SAHI library ka Python script banayen jo drawing ko 640x640 pixel ki choti tiles mein kate.
- Har tile ko trained YOLOv11 model se scan karwayen aur non-maximum suppression (NMS) lagayen.

Sub-phase 4.2: Text-Based Symbols (OCR)
- Jo symbols sirf text hote hain (e.g. VAV, BDD, 10x8), un keliye 'EasyOCR' ya 'PaddleOCR' Python mein integrate karein.
- YOLO aur OCR ki detections ko ek hi list mein combine karein.

---------------------------------------------------------
PHASE 5: BOQ EXPORT & AGGREGATION
---------------------------------------------------------
Sub-phase 5.1: Counting Logic
- Python dictionary banayen jo detected classes ko sum kare: {"Supply Diffuser": 13, "Return Vent": 8}

Sub-phase 5.2: Excel Generation
- 'pandas' library use karke detections ko DataFrame mein badlen.
- Us data ko DataFrame se '.xlsx' (Excel) file mein export karein BOQ format mein.

Sub-phase 5.3: Visual Proof Generation
- Ek aisi drawing save karein jis par har detect hone wala item mark ho (colored bounding boxes) take aap ya aapka client manually cross-check (audit) kar sake.

=========================================================
HOW TO USE THIS PLAN:
-> Hum ek waqt mein sirf ek "Sub-phase" uthayenge.
-> Jab aap ek sub-phase complete kar len, to mujhe batayen.
-> Fir hum next sub-phase ki script ya approach par kaam karenge.
